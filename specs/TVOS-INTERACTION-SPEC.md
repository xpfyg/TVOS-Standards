# tvOS Siri Remote 与交互规范

## 1. 核心原则

- 电视交互以焦点导航为中心，用户必须始终知道当前焦点在哪里、按下 Select 会发生什么、如何返回。
- 交互行为必须可预测；避免焦点突然消失、跳到屏幕另一端或在数据刷新后跳项。
- 系统原生行为优先；自定义行为必须明确理由，并测试边界情况。
- 所有核心流程都要考虑快速连续按键、长时间无操作、异步数据更新和网络失败。

## 2. 焦点状态与 SwiftUI

- 对需要程序化控制初始焦点或恢复焦点的页面，使用适合当前 SDK 的焦点管理 API，例如 `@FocusState`。
- `focusable`, `focusSection`、焦点作用域等 API 应根据实际导航结构使用，不要机械地给每个视图添加焦点修饰符。
- `onMoveCommand` 仅在系统默认方向导航不足、且产品设计明确需要自定义方向行为时使用。
- 焦点标识必须稳定；列表刷新、排序或异步更新不应无故更换 ID。
- 当焦点目标消失或变为不可用时，应定义合理的回退目标。
- 不要在每次 `body` 更新时强制重设焦点。
- 避免多个竞争的焦点状态源。

## 3. 导航与页面恢复

- 页面首次进入时，应将焦点放在合理的默认控件或内容项上。
- 从详情、弹窗或子页面返回时，尽可能恢复进入前的上下文与焦点。
- Tab/顶部导航、内容轨道和页面级控件之间的方向移动应符合用户预期。
- 弹窗打开后焦点应进入弹窗；关闭后回到触发弹窗的控件。
- 禁止焦点进入不可见、禁用或被遮挡到无法辨认的控件。
- 如果某方向没有合理目标，避免焦点意外跳转到不相关区域。

## 4. 内容轨道与网格

- 焦点卡片需要明确突出；轨道滚动与焦点移动应协调。
- 横向轨道左右移动时，焦点项应保持可见，并避免边缘裁切。
- 垂直跨轨道移动时，尽量落在空间位置合理的卡片上。
- 数据追加或刷新后保留当前焦点和滚动位置。
- 轨道为空时不应出现无法离开的焦点区域。
- 对异步图片，焦点框不应因图片加载完成而跳动。

## 5. 按钮与反馈

- 按钮标题应简洁并以动作导向。
- Select 激活后提供及时、适度的视觉或听觉反馈（遵循系统体验）。
- 长时间操作显示进度，并避免重复提交。
- 破坏性操作应提供确认或可撤销方案，具体取决于风险。
- 禁用控件需要明确的视觉状态，且不能伪装成可操作元素。

## 6. 菜单、弹窗与搜索

- 菜单和弹窗必须定义打开、关闭、取消、确认和返回行为。
- 用户按 Menu/Back 时，应遵循当前系统和应用导航约定，不要无故拦截系统手势。
- 搜索输入需支持系统允许的输入方式，包含空结果、加载、失败和重新搜索。
- 异步搜索应取消或忽略过期请求，避免旧结果覆盖新结果。
- 搜索清空、提交和返回后的焦点位置要明确。

## 7. 播放器交互

播放器必须覆盖以下状态：
- 初始加载、准备完成、播放、暂停、缓冲、播放失败、播放结束。
- 进度读取/拖动、音轨/字幕选择（若支持）、信息面板、选集、下一集。
- 自动连播应处理用户关闭设置、最后一集、网络失败、内容不可用和用户主动退出。
- 控件显隐策略、自动隐藏时机和焦点回归应清晰，且不能让用户失去暂停/退出路径。
- 对竖屏视频，主画面比例应正确；背景填充效果不能影响前景视频清晰度、字幕或控件可读性。
- 如果采用抽帧/模糊背景，应限制处理分辨率、缓存和更新频率，避免每帧重复昂贵处理。
- 暂停时的选集与剧集信息面板不应挡住核心画面或抢占不必要焦点。
- Dolby Vision、HDR、音视频格式与系统播放器能力必须以真实素材和目标设备验证，不可仅凭模拟器结果断言通过。

## 8. 网络与异步状态

- 请求中、空数据、失败、重试和离线状态都要有明确 UI。
- 页面离开后取消不再需要的任务。
- 避免重复请求、状态竞态和主线程上的重型图像处理。
- 网络错误文案应解释发生了什么，并提供下一步行动。
- 缓存策略必须明确失效规则，避免显示陈旧状态而不提示。

## 9. 无障碍

- 为自定义图标控件设置清楚的 VoiceOver 标签和适当的提示。
- 交互状态不能只通过颜色区分。
- 检查焦点、朗读顺序、标题语义和动态文字。
- 不要把纯装饰元素暴露为可操作控件。
- 对系统辅助功能行为进行实际验证。

## 10. 测试清单

- [ ] 首次进入页面焦点正确。
- [ ] 遥控器四方向移动符合预期。
- [ ] 焦点放大/高亮无裁切和遮挡。
- [ ] 页面返回恢复焦点与滚动位置。
- [ ] 快速连续移动焦点不丢失。
- [ ] 列表刷新、图片加载和异步结果不导致焦点跳转。
- [ ] 弹窗打开/关闭焦点正确。
- [ ] 空、加载、错误、离线状态可恢复。
- [ ] 播放器所有状态和切集流程可操作。
- [ ] VoiceOver 与系统辅助功能已按项目范围验证。
