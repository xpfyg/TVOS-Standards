# tvOS 质量与发布检查清单

## 状态定义

- `PASS`：实际执行并通过，有记录或证据。
- `FAIL`：实际执行并发现问题。
- `BLOCKED`：无法执行，明确说明阻塞原因。
- `NOT RUN`：尚未执行。
- `N/A`：确实不适用，并说明理由。

禁止仅凭代码阅读将构建、测试、真机 UI 或审核结果标为 `PASS`。

## 1. 需求与实现

- [ ] 需求范围、非目标和验收条件明确。
- [ ] 页面、状态、数据流、错误处理和焦点路径已梳理。
- [ ] 对现有架构的修改保持必要且可解释。
- [ ] 业务逻辑与展示逻辑边界清晰。
- [ ] 无硬编码密钥、测试账号或敏感数据。
- [ ] 新增依赖有必要性说明。

## 2. Swift 与工程

- [ ] 使用项目指定 Xcode、Swift 和 deployment target。
- [ ] 工程配置、资源目录、Target Membership 正确。
- [ ] 并发、任务取消和 UI 状态更新方式合理。
- [ ] 日志不输出 token、隐私数据或完整敏感请求。
- [ ] 无明显 retain cycle、重复任务或无界缓存。
- [ ] 错误路径和边界条件已处理。

## 3. 构建与测试

- [ ] 执行目标 scheme 的构建。
- [ ] 执行现有单元测试。
- [ ] 执行可用的 UI/集成测试。
- [ ] 新逻辑有针对性测试。
- [ ] 记录实际命令、设备/模拟器、结果和失败日志。
- [ ] 未执行的测试标为 `NOT RUN` 或 `BLOCKED`。

## 4. 视觉与交互

- [ ] 首屏层级与产品设计基线一致。
- [ ] 主要页面在目标电视尺寸和安全区域下可读。
- [ ] 所有可操作元素可通过 Siri Remote 聚焦和激活。
- [ ] 初始焦点、页面返回、弹窗和列表刷新行为正确。
- [ ] 焦点态不裁切、不遮挡、不抖动。
- [ ] 加载、空、错误、离线和禁用状态完整。
- [ ] 中英文和长文本布局已检查。
- [ ] VoiceOver 标签和辅助功能已检查。
- [ ] 已保存视觉证据；没有证据的真机检查不能声称通过。

## 5. 媒体与播放器（适用时）

- [ ] 支持的容器、编码、分辨率、HDR/Dolby Vision 和音频格式已明确。
- [ ] 加载、播放、暂停、缓冲、失败、结束和切集流程通过测试。
- [ ] 自动连播设置、最后一集和不可用内容路径正确。
- [ ] 字幕、音轨、进度恢复和播放控制按产品范围验证。
- [ ] 竖屏内容比例、背景填充和字幕可读性正确。
- [ ] 长时间播放、内存、解码和缓存表现可接受。
- [ ] 真机媒体格式测试与模拟器测试分别记录。

## 6. 性能与稳定性

- [ ] 首屏加载和焦点操作没有明显卡顿。
- [ ] 图片/视频资源有尺寸、缓存和生命周期策略。
- [ ] 动画与模糊效果不会造成明显掉帧。
- [ ] 网络超时、重试、取消和恢复行为正确。
- [ ] 长时间使用后无明显内存持续增长。
- [ ] 应用前后台切换和恢复行为已验证。

## 7. 隐私与合规

- [ ] 隐私政策和应用内数据说明与实际行为一致。
- [ ] 权限请求发生在合理场景，并解释用途。
- [ ] 收集的数据、第三方 SDK 和追踪声明已复核。
- [ ] App Privacy 信息与真实数据处理一致。
- [ ] 所有外部服务的条款、授权和内容版权已确认。
- [ ] 无隐藏功能、误导性描述或未经授权内容。
- [ ] 账号删除/数据删除要求（如适用）已满足。

## 8. 商店与签名

- [ ] Bundle ID、版本号、build number 正确。
- [ ] Signing Team、证书、profile 与目标配置正确。
- [ ] App 图标、截图、描述、分类、关键词和支持 URL 已准备。
- [ ] Top Shelf 等资源尺寸与规范匹配（如适用）。
- [ ] 隐私政策 URL、支持 URL 可访问。
- [ ] 付费、订阅、恢复购买和服务端校验流程已验证（如适用）。
- [ ] Archive、导出和上传流程实际验证。
- [ ] TestFlight 安装与核心流程回归完成。
- [ ] 提交前复核最新 Apple Developer / App Store Connect 要求。

## 9. 阶段门禁

### Gate A — 方案
- 需求和验收标准明确。
- 架构、UI、焦点和风险方案经过确认。

### Gate B — 功能完成
- 核心路径已实现。
- 单元/集成测试执行并记录。
- 未解决问题有明确负责人或下一步。

### Gate C — 候选版本
- 构建通过。
- 关键页面、遥控器流程和媒体流程已验证。
- 性能、隐私与回归风险已复核。

### Gate D — 商店提交
- 签名、元数据、素材、隐私信息和支持链接完整。
- TestFlight 或等效发布前检查完成。
- 提交内容与实际应用行为一致。
