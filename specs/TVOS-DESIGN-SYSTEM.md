# tvOS 26 设计系统规范

> 目标：建立适合电视观看距离、遥控器焦点操作和沉浸式内容浏览的视觉系统。数值是项目起始建议，不是 Apple 对所有应用的强制值；应结合真实设备、系统版本和内容密度验证。

## 1. 设计优先级

1. 内容识别与选择效率。
2. 远距离可读性。
3. 清楚的焦点位置与导航方向。
4. 品牌一致性和页面节奏。
5. 动效、材质与装饰。

不要用玻璃效果、渐变或阴影掩盖信息层级不足。优先使用系统原生控件和材质；自定义视觉必须保留清晰的焦点与对比度。

## 2. 画布与布局

- 以项目目标设备和目标 tvOS 版本的实际安全区域为准，不要硬编码假设所有电视都显示完全相同的可视区域。
- 采用大区块、明确分组和充足留白，避免手机式密集布局直接放大。
- 首屏优先突出核心内容、主要入口与可继续浏览的内容轨道。
- 横向内容轨道应有明确的标题、内容数量/状态（需要时）及可预期的焦点移动方向。
- 关键操作不要贴近屏幕边缘；长标题、不同语言与系统显示设置都要测试。
- 视觉比例应在真实电视或 tvOS Simulator 中验证，不以桌面预览代替。

## 3. 设计 token 建议

请将实际 token 收敛到项目统一位置，例如 `DesignTokens.swift`。以下仅为初始基准：

| 类别 | 起始建议 | 说明 |
|---|---:|---|
| 页面水平边距 | 64–96 pt | 依导航和内容密度调整 |
| 大区块间距 | 40–64 pt | 用于主要区域分隔 |
| 组件间距 | 16–32 pt | 避免过密 |
| 小间距 | 8–12 pt | 仅用于紧密关联元素 |
| 海报比例 | 按内容源 | 不要强制裁切关键主体 |
| 焦点放大 | 约 1.04–1.10 | 需实机验证，避免遮挡邻项 |
| 动画时长 | 约 0.18–0.35 s | 状态动效应快速、可预测 |

- 颜色使用语义 token：`background`, `surface`, `surfaceElevated`, `textPrimary`, `textSecondary`, `accent`, `separator`, `focus`。
- 不要在多个视图中散落相同颜色的硬编码值。
- 确保文本和背景对比度足够；焦点不能只靠细微色差表达。

## 4. 字体层级

建立清楚且有限的层级：
- Hero 标题：用于首屏核心内容，不应成为每个区块都使用的默认标题。
- 页面标题：标识当前页面。
- 轨道标题：帮助识别内容分组。
- 卡片标题：在远距离下能快速辨认。
- 辅助信息：评分、时长、进度、标签等，不与标题争夺注意力。
- 控件文字：短、明确、动作导向。

优先使用系统字体和动态字体样式。确需固定字号时，说明理由并检查不同语言、超长文本和可访问性设置。

## 5. 内容卡片与海报

- 卡片形状、尺寸和间距应由内容类型决定；电影海报、竖屏短剧、游戏入口、人物头像不应无差别套用一种卡片。
- 默认状态需要显示足够信息；焦点态可以增加缩放、描边、材质或信息，但不能让布局剧烈跳动。
- 焦点放大时应考虑邻项遮挡、轨道裁切与边缘卡片。
- 海报加载失败、缺失、低分辨率和比例不符时必须有一致的占位策略。
- 对背景大图使用渐变或遮罩保证文字可读；不能只依赖源图片本身够暗。

## 6. 页面结构

- 导航层：当前区域清楚，焦点切换可预测。
- 主内容层：用层级和尺寸强调最重要的内容。
- 轨道/列表层：保持重复模式一致，但允许不同内容类型采用不同比例。
- 详情层：优先显示标题、简介、主要动作和必要元信息；次要信息按需展开。
- 设置层：分组、解释和当前状态明确。
- 空、加载、错误、无网络状态都应符合整体设计，而不是临时默认文本。

## 7. 焦点视觉

- 所有交互控件必须有明显焦点态，且焦点态与选中态语义不同。
- 选中状态可持续存在；焦点状态随遥控器移动变化。
- 焦点效果不得造成文字抖动、内容裁切、相邻卡片遮挡或背景闪烁。
- 对自定义焦点动画，应验证快速连续移动、长轨道边缘、弹窗和页面返回。
- 不要用过度夸张的缩放让内容在电视上频繁跳动。

## 8. 动效与材质

- 动效服务于焦点、页面转场、状态变化和空间关系。
- 避免多个大范围模糊层、持续运行的视频背景或大量同步动画造成 GPU/内存压力。
- 动画应能处理中断、快速重复输入和视图销毁。
- 尊重系统减少动态效果等可访问性设置。
- 使用 Liquid Glass 或类似材质时，确保文本对比度、焦点边界和层级清晰；不要为了模仿材质而降低可读性。

## 9. 可访问性与国际化

- 文本、图标、状态和焦点共同传达信息，不依赖单一颜色。
- 为图标按钮提供 VoiceOver 标签；装饰图像避免冗余朗读。
- 检查中文、英文、德文等长短差异，以及数字、时间和字幕格式。
- 对文本截断给出合理规则；关键动作名称不能被截断到无法理解。
- 所有交互应能通过 Siri Remote 完成，不依赖触摸、鼠标或键盘悬停。

## 10. 验收

- 在目标 tvOS Simulator 和可用真机上检查首屏、内容轨道、详情、设置、弹窗和播放器。
- 验证焦点态、非焦点态、选中态、禁用态、加载态、空态和错误态。
- 用真实内容素材验证裁切、对比度、海报比例和长文本。
- 记录截图或视频证据，并列出尚未验证的设备或状态。
